# Хостинг: как держать бота в облаке 24/7

Локальный запуск на твоём ПК работает, но требует включённого компьютера и VPN
(на твоём интернете `api.telegram.org` блокируется). На хостинге Telegram доступен напрямую,
никакого VPN не нужно.

## Что понадобится

1. Код на GitHub (см. `README.md` → «Как выложить на GitHub без git»).
2. Аккаунт на хостинге, который умеет запускать Docker-контейнер **без** HTTP-порта
   (бот работает через long polling — порт ему не нужен):
   - **Railway** — проще всего: `New Project` → `Deploy from GitHub repo` → выбрать репозиторий.
     Railway сам найдёт `Dockerfile`.
   - **Render** — `New` → `Background Worker` → подключить репозиторий → Runtime: Docker.
   - **Fly.io / VPS** — через `fly deploy` или `docker compose up -d`.
   - **Бесплатные варианты без карты** — почти всегда усыпляют сервис, а уснувший бот
     не читает сообщения. Для стабильной работы нужен платный минимальный тариф.

## Переменные окружения (в панели хостинга)

Вместо `config.json` на хостинге задай переменные — бот читает их в первую очередь:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | новый токен от @BotFather (старый, который светился в чате, отзови!) |
| `DEEPSEEK_API_KEY` | ключ `sk-...` с platform.deepseek.com |
| `DEEPSEEK_MODEL` | `deepseek-chat` |
| `MODE` | `suggest` (для начала) |
| `DATA_DIR` | `/data` |
| `OWNER_CHAT_ID` | твой числовой chat_id (бот напишет его при `/start`) |
| `PROXY` | не нужен |

## Постоянный диск (важно!)

База `bot.db` лежит в `DATA_DIR`. Если не подключить постоянный диск (volume) к `/data`,
то при каждом обновлении бота вся история, заметки и память о людях исчезнут.

- Railway: `Service` → `Settings` → `Volumes` → добавить `/data`
- Render: `Disks` → `Add Disk` → Mount path `/data`
- Fly.io: `fly volumes create botdata` и примонтировать в `/data`

## Первый запуск на хостинге

1. Задеплой репозиторий, дождись статуса «running» в логах — должно появиться
   `Run polling for bot @...`.
2. Открой бота в Telegram, напиши `/start` — этот чат станет пультом владельца.
3. *Настройки → Telegram Business → Чат-боты* → подключить бота (права «Читать сообщения»
   и «Отвечать на сообщения»).
4. Попроси кого-нибудь написать тебе — придёт черновик ответа.

## Что важно не забыть

- **Нельзя запускать два экземпляра с одним токеном.** Если бот ещё работает на ПК и ты
  поднял его же на хостинге — один из них будет падать с ошибкой `Conflict`.
  Перед деплоем останови локальный (`Ctrl+C` в терминале).
- **Обновление кода**: залил новые файлы скриптом публикации → хостинг сам пересоберёт контейнер.
- **Секреты только в переменных окружения хостинга.** `config.json` в репозиторий не попадает
  (он в `.gitignore`), и это правильно.
- **Логи** — единственное место, где видно проблемы: `Ctrl+F` по `ERROR`, `Conflict`, `401`.
